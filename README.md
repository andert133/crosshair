# Rust Crosshair Overlay & Configurator

Высокооптимизированный, пиксельно-симметричный игровой прицел-оверлей, написанный на Rust. Обладает веб-панелью управления, работает в фоновом режиме (в системном трее) и практически не потребляет ресурсы ПК.

## 🚀 Особенности и преимущества

* **Экстремальная оптимизация ресурсов**:
  * Потребление физической оперативной памяти (RAM) — **всего 10.89 МБ**.
  * Нагрузка на процессор (CPU) — **0.00%** во время игры (перерисовка происходит через нативный Windows GDI только при изменении настроек).
  * Размер скомпилированного Release-файла — **всего 304 КБ**.
* **Сверхточная геометрия (Pixel-Perfect)**:
  * Встроенная поддержка DPI-масштабирования Windows предотвращает размытие или искажение («лесенку») линий.
  * Абсолютная пиксельная симметрия со всех четырех сторон для любых размеров зазоров и толщины линий.
  * Идеальная центровка на любых нестандартных разрешениях экрана и конфигурациях с **несколькими мониторами** (прицел центрируется на том мониторе, где находится курсор при запуске).
* **Современный Web-интерфейс**:
  * Панель управления на localhost (`http://127.0.0.1:25432`) со стильным темным дизайном (Glassmorphism).
  * Интерактивные слайдеры для мгновенного изменения длины, толщины, зазоров и смещения осей (X/Y) в реальном времени.
  * Встроенная панель предпросмотра прицела.
* **Глобальный хоткей**:
  * Включение/выключение прицела «на лету» одной кнопкой (по умолчанию **Ctrl + Alt + C**, настраивается в браузере).
* **Автозапуск с Windows**:
  * Опция добавления в автозагрузку через реестр Windows (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`) прямо из настроек.
* **Управление из трея**:
  * Кастомная иконка в системном трее (возле часов). Левый клик открывает настройки, правый клик — контекстное меню (Вкл/Выкл, Настройки, Автозапуск, Выход).

## 🛠️ Как собрать проект (Компиляция)

Для сборки проекта вам понадобится установленный компилятор Rust. Если у вас его нет, скачайте его с официального сайта [rustup.rs](https://rustup.rs/).

1. Откройте терминал/консоль (CMD/PowerShell) в папке `crosshair`.
2. Выполните сборку оптимизированной Release-версии:
   ```bash
   cargo build --release
   ```
3. Готовый оптимизированный файл `rust-crosshair.exe` появится в папке:
   `target/release/`

## 🎮 Как запускать и использовать

Для максимального удобства используйте лаунчер:
1. Запустите файл **`run.bat`** двойным кликом.
2. Прицел запустится в фоне (полностью бесшумно, без окон консоли), а в вашем браузере автоматически откроется страница настроек `http://127.0.0.1:25432`.
3. Настройте прицел под себя. Закройте вкладку браузера — прицел продолжит работать в фоне.
4. Нажмите **Ctrl + Alt + C** в любой момент, чтобы временно скрыть или показать прицел.
5. Для полного выхода из приложения нажмите правой кнопкой мыши на иконку прицела в трее и выберите **Выход** (или нажмите «Закрыть приложение» внизу веб-панели).
